CrowPSX

HLSL · Unity Built-in & URP · sold on the Asset Store

A retro rendering suite for Unity that reproduces the PS1's quirks on purpose: vertex snapping, affine texture warping, low-precision color. It covers surfaces, four-layer vertex painting, terrain, foliage with anchored wind, particles, decals and a procedural sky, so a whole scene can be built in one style.

A lot of the effort went into things nobody screenshots: a batch Material Manager, inspectors with presets and diagnostics, snapping that stays stable across both eyes in VR, and a docs site covering every shader and tool in the package.

FlashGuard

C++20 · Direct3D 11 · DXGI Desktop Duplication

An experimental overlay for people who are sensitive to flashing light. It captures the desktop, figures out on the GPU which regions are flickering at hazardous frequencies, and limits how fast the displayed image can change while leaving ordinary motion alone. The overlay is click-through and excluded from capture so it never sees its own output.

260/260surface-path checks passing on an RTX 3060
74.17%on the hardest case, against a 70% bar I didn't lower
2CI workflows: build, plus a GPU smoke test

It's alpha software and says so. The README carries a warning that it isn't medically validated, and it keeps a written diagnosis of the one real-world artifact that's still open.

CrowFX

C# · HLSL · Built-in, URP and HDRP · on OpenUPM

  • CRT
  • Dither
  • Posterize
  • RGB bleed

Free post-processing for Unity that turns a camera into a CRT, a worn VHS tape, damaged film, or a PSX-era framebuffer. It ships 88 curated looks in 11 categories. Each inspector section previews through the real stage shader, and an effect you switch off adds no render pass. Of everything I've published, this one has the most stars.

StatementCheck

Vanilla JS · runs entirely in the browser

Bank CSV exports are a mess: three date orders, two decimal separators, debits that are sometimes negative and sometimes a separate column. StatementCheck maps the columns, normalizes signs and dates, and writes a Xero-ready file alongside an audit CSV explaining every warning and rejected row.

Files never leave the browser. Later commits went after the quiet failures: amounts now keep exact cents, conflicting sign columns get rejected instead of guessed, and cells that start like spreadsheet formulas are blocked.

Use it Xero CSV guide

How I work

I like software you can read from top to bottom. Most of my sites are the exact files the browser gets, and they keep working when the script doesn't load.

Docs count as part of the work. CrowPSX has its own documentation site, and the FlashGuard README spends as long on what's still broken as on what works.

I'd rather publish a number I can defend than a nicer one. FlashGuard's pass threshold has stayed at 70% through every rewrite.

My own packages get used together in CrowHorror, a horror game foundation, so I run into their rough edges before anybody else has to.
